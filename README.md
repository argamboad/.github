# argamboad/.github

The default community files for every repo under argamboad (Pkg 5.5, argamboad/perezosoft-platform#418): the pull
request template, the contributing guide and the issue forms. GitHub shows them in any repo that keeps none of its
own; a repo that does keep one (the platform keeps its PR template and its CONTRIBUTING) shows its own.

Change them here, once, for every repo — not in a copy.
